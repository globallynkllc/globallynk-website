# GlobalLynk LLC — Website

Website for GlobalLynk LLC, an international general trading company (Sheridan, Wyoming, USA).

**Live site:** https://globallynkllc.com

Plain HTML, CSS and JavaScript — no build step.

## Preview locally

```
python -m http.server 8000
```

Then open http://localhost:8000

## Pages

- `index.html` — Home
- `products.html` — Nonwoven fabrics, electric mountain bikes, auto spare parts, baby products
- `markets.html` — Markets & logistics
- `contact.html` — Request a quote

## Deploy

GitHub Pages is enabled (deploy from `main` / root). Push to `main` and the live site updates within a minute or two.
